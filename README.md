# Stone Lock

An installable static web app for iPad and other modern browsers.

## Publish with GitHub Pages

1. Put these files at the root of the `DND-Lock` repository on the `main` branch.
2. In **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
3. Push to `main`. The Pages workflow deploys the app at `https://maiktimmermans-lgtm.github.io/DND-Lock/`.

The app and its assets will be public at that address.

## Install on iPad

After deployment, open the Pages URL in Safari, tap **Share**, then **Add to Home Screen**. Launch the installed app from its Home Screen icon.
